# ❄️ 卡卡查克 · 雪原冒险

一个极地主题的每日打卡与专注力培养网页游戏。在雪原上陪伴旅行者，记录每一次专注，收集卡牌，与旅行者共同面对暴风雪。

## ✨ 功能特性

- **📝 每日打卡**：记录任务与专注时长，支持单条删除和全部清除。
- **🍅 番茄钟**：可自定义时长的专注计时器，自动计入打卡时长，专注越久获得的掉落物品越珍贵。
- **🎴 卡牌收集**：打卡抽卡 + 专注掉落，每种物品都有专属文案和效果。
- **🗺️ 冒险报告**：每隔30分钟自动刷新天气与事件，旅行者的四项数值（温度、健康、饱腹、心情）会随时间变化，背包物品会在状态低下时自动使用并记录日志。
- **🎒 背包系统**：查看所有卡牌详情与属性加成，可赠送给旅行者。
- **📊 历史统计**：打卡天数、连续打卡天数、各任务累计时长等。
- **💾 本地保存**：所有数据保存在浏览器 localStorage 中，不同用户/设备互不影响。

直接访问：`https://umlla.github.io/kaka-checker`


## 🎮 玩法指南

| 操作 | 说明 |
|------|------|
| **打卡** | 在任务栏输入任务名和专注分钟数，点击“打卡”按钮。 |
| **番茄钟** | 选择或自定义时长，点击开始。计时过程中可暂停或停止，停止后自动记录打卡。 |
| **抽卡** | 每天有打卡记录后，点击“抽卡”获得随机卡牌；连续7天可得传说彩蛋。 |
| **使用卡牌** | 进入背包，点击卡片的“使用”按钮，会显示专属使用文本（消耗卡牌）。 |
| **赠送卡牌** | 进入背包，点击卡片的“赠送”按钮，旅行者会感谢你，物品进入旅行者背包。 |
| **冒险日志** | 切换至“冒险”面板可查看当前天气、事件、旅行者状态及自动使用物品的日志。 |
